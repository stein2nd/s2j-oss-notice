# ADR-002: 出力フラグ `-o` と `--out-file` (D-006)

**状態:** 採用  
**日付:** 2026-11-25

## 決定 `{@002-output-flags:s-h001}`

`-o` にファイルパスを渡す onot 互換モードは **サポートしません**。

| モード | 出力指定 | 挙動 |
| --- | --- | --- |
| **onot 互換** (L1/L2) | `-o` / `--output` = **既存ディレクトリまたは作成するディレクトリ** | 配下に `OSS_Notice_*.md` 等 (onot 同様) |
| **S2J ネイティブ** (L0) | **`--out-file`** = ファイルパス | 単一 Markdown 等を直接書き込み |
| 判別 | 入力が **SPDX/CycloneDX** か **lockfile** か + `--out-file` の有無 | あいまい時は onot 互換を優先 (`-o` がディレクトリ必須) |

## 理由 `{@002-output-flags:s-h002}`

Ack / onot は `-o` をディレクトリとして使う。lockfile 直通で単一ファイルに書く用途は **`--out-file`** で分離し、パーサーの誤判定を防ぐ。

正本: [cli.md](../cli.md)。
